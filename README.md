# Happyish first version

Standalone static website. Light mode is the first-visit default; theme choice persists locally. Original supplied logo artwork is displayed using a CSS viewport selecting its light/dark half; the file is unmodified.

Serve with `python3 -m http.server 8800` from this directory.

Insights is an honest coming-soon page. No CMS separation, database migration, publishing integration or deployment has been performed. These require checking the live existing schema and adding a site discriminator consistently to publishing, queries, archives and sitemap rendering. AiGENCY remains untouched.

Contact uses the supplied existing email and phone, without a data-collecting form. Review operational privacy arrangements before collecting mentoring records.
